# Anti-Patterns in Knowledge Management

Common mistakes that undermine a second brain's effectiveness. Each anti-pattern is documented as a separate atomic note.

> Knowledge about what doesn't work is as valuable as knowledge about what works. A knowledge base that only captures successes is incomplete.

## Applying Best Practices

The vault uses a systematic approach: for each anti-pattern failure mode, there's a corresponding best practice solution. This section provides practical guidance for implementation.

### Core Implementation Guidelines

#### 1. Capture Quality

Before capturing any note, apply the **Diminishing Returns Test**:

1. **Utility** — Does this improve vault answers?
2. **Connection** — Does this connect to 2+ existing notes?
3. **Uniqueness** — Does this add new knowledge?
4. **Effort** — Is maintenance worth the value?

**Skip if it fails 2+ criteria.**

#### 2. Best Practices for Creating Best Practices

When creating best practice notes:

1. **Pair with anti-pattern** — Each best practice should explicitly reference its corresponding anti-pattern
2. **Use positive framing** — State what to do, not just what to avoid
3. **Include actionable test** — How does someone verify they're following this?
4. **Provide examples** — Show what success looks like
5. **Keep it atomic** — One best practice per note

### The Balance Rule

For every dedicated negative knowledge note, there should be a corresponding positive note showing the right approach. Don't let the negative overwhelm the positive.
