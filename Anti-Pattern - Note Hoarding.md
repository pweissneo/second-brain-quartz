# Anti-Pattern: Note Hoarding

> This anti-pattern has been merged into [[Best Practice - Selective Capture]].
> The content about note hoarding (failure modes, signs, solutions) is now captured in that best practice note.

## Why This Exists

This note remains as a redirect to preserve any links pointing here. The anti-pattern content was merged into the best practice because:
- The anti-pattern and best practice shared substantial content (two-phase workflow, diminishing returns test)
- Positive framing is more actionable than negative framing
- Having both creates maintenance burden (two places to update)

## What Was Covered

The original anti-pattern covered:
- Processing failure (capturing without processing)
- Selection failure (capturing noise)
- Timing confusion (trying to fully process at capture time)

All of this is now covered in [[Best Practice - Selective Capture]].
