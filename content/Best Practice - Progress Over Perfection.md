# Best Practice - Progress Over Perfection

> Publish early, refine later. Perfect notes don't exist — useful ones do.

## The Principle

Perfectionism is never publishing because it "isn't ready." The alternative is progress — capture what's useful now, refine later. A good note today beats a perfect note never.

## The Refinement Cycle

Notes evolve through stages:
1. **Whisper** — Initial capture, rough notes
2. **Draft** — Structured but unverified
3. **Refined** — Verified and polished
4. **Evergreen** — Stable, regularly reviewed

Not every note needs to reach "evergreen." Some stay useful at "draft."

## When to Publish

Capture when:
- You understand enough to be useful
- The note would help your future self
- You can explain the core idea

Refine when:
- You learn something that updates the note
- You find the note is hard to understand
- Others will use it

## The Test

Ask: "Would my future self thank me for having this note?"

If yes, capture it. Even if rough.

## Why Perfectionism Fails

1. **Time costs** — Perfecting takes forever, delays capture
2. **Requirements shift** — What you think matters changes
3. **Iteration improves** — Refining after use is more effective than pre-perfecting

## The Alternative Mindset

Think of notes as living documents, not finished products. "Good enough" today becomes better tomorrow — but only if captured.
