# Anti-Pattern: Missing Negative Knowledge

> **DEPRECATED (2026-04-02):** This anti-pattern has been merged into [[Best Practice - Balanced Capture]]. The content is now captured in the best practice note, which provides both the positive guidance and the failure mode it prevents.

## Original Content (Preserved for Reference)

Only capturing successes, not failures, creates an incomplete picture.

### The Problem

Missing negative knowledge means:
- No anti-patterns documented
- No lessons learned from mistakes
- No warnings about what doesn't work

The vault only shows one side of the story.

### The Solution

Document failures, dead ends, and warnings. Link negative knowledge to the positive alternative.
