# Tool Replacement Decisions

When to switch knowledge management tools vs. when to migrate content.

## The Core Question

You've invested time building knowledge in one tool. When does it make sense to switch tools rather than continue with the current one?

## Decision Framework

### Stay If:
- Current tool meets 80%+ of needs
- Migration cost > improvement gain
- Lock-in is acceptable (export available)
- Workflow is established and productive

### Switch If:
- Tool is abandoned or unmaintained
- Fundamental limitations prevent core workflows
- Data export is becoming impossible (format changes)
- Security/privacy requirements change fundamentally

### Migrate Content If:
- New tool has better structure for your evolved needs
- Old tool format is degrading (bit rot, format obsolescence)
- You're starting fresh with new methodology

## Cost-Benefit Analysis

| Factor | Stay | Switch |
|--------|------|--------|
| Time to migrate | 0 | High |
| Learning curve | Low | High |
| Workflow disruption | None | Significant |
| Potential improvement | Incremental | Transformative |

## The 80/20 Rule

If current tool serves 80% of needs, the 80% improvement from switching rarely justifies the 100% cost of migration. The last 20% isn't worth the switch cost unless it's blocking critical functionality.

## Anti-Pattern Warning

See [[Anti-Pattern - Tool Overfocus]] — switching tools as optimization is different from switching as procrastination. If you're constantly evaluating alternatives, the tool isn't the problem.

## Migration Principles

1. **Export first** — Always verify export works before committing
2. **Selective migration** — Not everything survives; prune aggressively
3. **Reorganization opportunity** — Migration is a chance to restructure, not just port
4. **Test period** — Run both tools in parallel for 2-4 weeks

## Test Criteria (for AI Evaluation)

- [ ] Is the current tool actually blocking a core workflow?
- [ ] Have you used the current tool consistently for 6+ months?
- [ ] Can you name 3 specific features missing from current tool?
- [ ] Does new tool solve those 3 specifically?
- [ ] Have you tested new tool for 2+ weeks before migrating?
