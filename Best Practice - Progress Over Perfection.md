# Best Practice: Progress Over Perfection

> A good note today beats a perfect note never. Capture the core idea, refine over time.
> This note consolidates both **Selective Capture** (capture workflow) and **Progress Over Perfection** (refinement workflow).

> **Note (2026-04-08):** This note now consolidates both "Best Practice - Selective Capture" and "Best Practice - Progress Over Perfection." Both anti-patterns (Note Hoarding and Perfectionism) have been merged here — their files have been removed. The vault now has one comprehensive best practice for capture and refinement workflows.

## The Core Principle

A good note today beats a perfect note never. Capture what's useful now, refine over time.

**Two-phase workflow:**
1. **Capture** — Quick save, any format, get the idea down. No structure required. Stay in flow.
2. **Process** — Within 48 hours, transform into atomic notes with links. This is where structure happens.

Never try to fully process notes at capture time — it leads to either no capture (ideas lost) or no processing (note hoard). The goal of capture is to capture; the goal of processing is to structure. They have different mindsets and belong in different sessions.

## The Problems This Solves

### Problem 1: Note Hoarding

Saving everything without processing undermines a second brain's effectiveness. Note hoarding manifests in three ways:

**1. Processing Failure:** Capturing without processing leads to:
- Hundreds of unprocessed bookmarks
- Notes that are just copied text
- No links between notes
- The vault becomes a graveyard of unconnected fragments

**2. Selection Failure:** Capturing noise clutters the vault:
- Notes on easily retrievable information
- Ephemeral content that won't be referenced
- Duplicate knowledge
- Capturing during momentum instead of staying in flow

**3. Timing Confusion:** Trying to fully process at capture time breaks the workflow:
- Time spent capturing but never processing
- No distinction between quick capture and processed notes
- Ideas lost before they can be captured

### Signs of Note Hoarding

- Inbox never gets processed
- Notes are verbatim copies from sources
- No wikilinks exist between notes
- Notes that are just facts a web search finds in 5 seconds
- One-off conversation notes
- Duplicate content already in vault
- Capture breaks your flow
- Every note takes 30+ minutes to create (trying to process at capture)

**Tool-focused (related failure mode):**
- More time researching tools than creating content
- Notes about tools but no substantive content notes
- Vault is "setup" but nearly empty after 30+ days
- Can't remember the last time a content note was created

### Problem 2: Perfectionism

Never publishing a note because it's "not ready" stops all progress. Perfectionism manifests as:
- Notes remaining in "draft" status for >30 days
- No new notes created for weeks or months
- Single notes revised repeatedly without progressing
- Vault stagnates while chasing impossible standards

### Signs of Perfectionism in the Vault

1. **Draft Age Test**: Are any notes in "draft" status older than 30 days?
2. **Capture Rate Test**: Has it been more than 14 days since a new note was created?
3. **Revision Loop Test**: Have any single notes been revised more than 5 times without progressing to "active" status?

If 2+ apply, perfectionism may be blocking progress.

## The Note Lifecycle

Notes evolve through stages:

1. **Whisper** — Initial rough capture. Any format. Just signal.
2. **Draft** — Structured but unverified. Has core idea, needs polish.
3. **Refined** — Verified and polished. Ready for regular use.
4. **Evergreen** — Stable, well-connected, regularly reviewed.

Not every note needs to reach "Evergreen." Some stay useful at "Draft."

## The Diminishing Returns Test

Before capturing any note, evaluate it against four criteria:

1. **Utility** — Does this improve vault answers? Would it help answer questions you actually have?
2. **Connection** — Does this naturally connect to 2+ existing notes? Can you explain the connections?
3. **Uniqueness** — Does this add knowledge that doesn't already exist in the vault?
4. **Effort** — Is the maintenance burden worth the value this provides?

**Skip if it fails 2+ criteria.**

### The Reverse Test

Ask before creating any note:

**Will I need this in 6 months?**
- Does this connect to something I already know?
- Is this my insight or someone else's?
- Can I find this in 30 seconds on the web?

If no → skip. Your second brain will thank you.

## When to Capture

Capture knowledge that:
- You'd actually search for later
- Provides context you can't find elsewhere
- Represents your unique perspective or experience
- Connects to knowledge you already have

Capture when:
- You understand enough to be useful to your future self
- The note would help answer a question you have
- You can explain the core idea in one sentence

Refine when:
- You learn something that updates the note
- You find the note is hard to understand
- Others will use it
- It fails the diminishing returns test (needs strengthening)

## When NOT to Capture

| Type | Why Skip | Alternative |
|------|----------|-------------|
| Easily retrievable | Web search finds it fast | Don't capture |
| Ephemeral | One-off, won't reference | Process if it creates insight |
| Duplicate | Already exists | Update existing note |
| Momentum capture | Breaks flow | Jot quick note, process later |

## Why Perfectionism Fails

1. **Time costs** — Perfecting takes forever, delays capture
2. **Requirements shift** — What you think matters today changes
3. **Iteration improves** — Refining after use is more effective than pre-perfecting
4. **Context decays** — The context that makes a note valuable fades quickly

Think of notes as living documents, not finished products. The Seed's [[Note Lifecycle Management]] rule defines explicit stage transitions — use them.

## The Test

Ask: **"Would my future self thank me for having this note, even rough?"**

If yes → capture it.

## Test Criteria (for AI Evaluation)

- [ ] Are notes in draft status processed within 30 days?
- [ ] Is the vault growing (new notes created within last 14 days)?
- [ ] Do revised notes progress to active status after revisions?
- [ ] Does the vault contain notes at all lifecycle stages (whisper → draft → refined → evergreen)?
- [ ] Can you find examples of notes that started rough and became valuable through iteration?
- [ ] Are captured notes processed within 48 hours?

## Capture the Negative Too

Progress applies to negative knowledge as well. Don't wait to document failures until you're sure. Capture what didn't work when you learn it.
