### Quick Reference: Diminishing Returns Test

Before capturing any note, evaluate:

1. **Utility** — Does this improve vault answers?
2. **Connection** — Does this connect to 2+ existing notes?
3. **Uniqueness** — Does this add new knowledge?
4. **Effort** — Is maintenance worth the value?

**Skip if it fails 2+ criteria.**

## Best Practices for Creating Best Practices

When creating best practice notes:

1. **Pair with anti-pattern** — Each best practice should explicitly reference its corresponding anti-pattern
2. **Use positive framing** — State what to do, not just what to avoid
3. **Include actionable test** — How does someone verify they're following this?
4. **Provide examples** — Show what success looks like
5. **Keep it atomic** — One best practice per note
